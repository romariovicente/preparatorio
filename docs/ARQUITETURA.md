## Mobile

O usuário poderá selecionar:

"Estou jogando no telefone"

e ativar automaticamente:

- joystick virtual
- câmera por toque
- botão de interação
- mapa
- inventário
- atalhos

O teclado virtual do aparelho será utilizado para formulários, chat e textos.

## Veículos

O jogador receberá veículos iniciais dentro das regras do universo.

O sistema futuro permitirá:

- comprar
- vender
- trocar
- personalizar
- abastecer
- modificar
- acoplar reboques
- utilizar veículos em atividades
