# PREPARATÓRIO

## Do Técnico de Enfermagem à Medicina

Criador: Romario Vicente Amaro

Jogo brasileiro educacional, multiplayer e 3D.

### Conceito

O PREPARATÓRIO será um mundo virtual brasileiro com:

- Hospital
- UPA
- Ambulância
- Farmácia
- Universidade
- SENAC
- UFAL
- Centro de pesquisa
- Praia
- Pesca
- Barcos
- Jet skis
- Helicópteros
- Aviões
- Veículos terrestres
- Corridas
- Cidade explorável
- Multiplayer
- Anatomia 3D
- Educação em saúde
- Sistema de profissões
- Sistema de progressão
- Comunidade

### Câmeras

- Terceira pessoa: padrão inicial
- Primeira pessoa: opcional

### Plataformas

- Navegador
- Celular
- Computador

### Tecnologias

Frontend:
JavaScript
React
Vite
Three.js
React Three Fiber

Backend:
Java
Spring Boot
WebSocket

Banco:
PostgreSQL

## Regra de conteúdo

O jogo possui foco educacional e escolar e não terá violência como mecânica principal.
